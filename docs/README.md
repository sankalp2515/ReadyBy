## Historical records

Files titled V2, earlier implementation plans, PM evaluations, film reviews and the 0.3 handoff describe earlier project states. They are retained for development provenance. Their local-only statements, older counts, model choices and media references do not supersede the guides above. Some historical raw captures remain local and are deliberately not included in this public repository.

The PNG/SVG named `readyby-actual-architecture` documents the retained 0.3 text/MCP path. Use the current Mermaid diagrams for the hosted voice implementation. Older walkthroughs are labelled evidence montages, not a continuous recording of the current application.

The [v0.4.0 release](https://github.com/sankalp2515/ReadyBy/releases/tag/v0.4.0) is an immutable reference to the original code and source bundle. Documentation cleanup on `main` does not change that release.
